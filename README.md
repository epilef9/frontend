# Frontend Barbería

## ¿Qué hace el proyecto?
Interfaz visual (cliente web) de la aplicación de la barbería. Desarrollada utilizando React y empaquetada con Vite para un rendimiento óptimo. Permite a los usuarios interactuar de manera gráfica con el sistema (iniciar sesión, registrarse, agendar, ver perfiles). Se comunica con la capa BFF a través de la librería Axios.

## Cómo instalar dependencias
Asegúrate de tener Node.js instalado. Abre tu terminal en la raíz de la carpeta frontend y ejecuta:
```bash
npm install
```

## Cómo ejecutar (comandos)
Para iniciar el servidor de desarrollo en local con Hot-Reloading:
```bash
npm run dev
```
